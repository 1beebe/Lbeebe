What is an AI agent, and how is it different from a ChatGPT chat?

A chat answers your message and waits. An agent takes a goal and works through the steps until it's done or needs you.

Edited by Ligaya Beebe · November 30, 2026

How this post was made: a site bot drafted this from OpenAI's practical guide to building agents, OpenAI's ChatGPT Work guide and help pages, and Anthropic's engineering post on building effective agents, then ran revision passes. Ligaya Beebe reviewed and approved it before it went live. Nothing on this blog publishes itself.

The short answer: OpenAI defines agents as "systems that independently accomplish tasks on your behalf." In a ChatGPT chat, you send a message, it replies, and it waits for you. An agent takes a goal, works out the steps, uses tools like a browser or your connected apps, checks how it's doing, and comes back when the job is finished or it needs you. OpenAI's own guide says a simple chatbot that doesn't run the workflow isn't an agent.

TL;DR

  • A chat responds to one message at a time. You decide every next step.
  • An agent works toward a goal across several steps and chooses its own tools along the way.
  • In ChatGPT, agent-style work now happens in Work, which can use a cloud browser and connected apps and pauses for your approval on big actions.
  • Agents take more time and credits, and they can make bigger mistakes. Use a chat when a chat is enough.

What does "AI agent" actually mean?

The word gets used for almost anything, so it helps to start with the definitions from the companies that build the models.

OpenAI's practical guide to building agents says an agent has two core traits. It uses an AI model to manage the steps of a task and make decisions, including recognizing when the task is complete and handing control back to you if it fails. And it has tools to gather information and take actions in other systems, which it picks based on where the task stands. The guide boils an agent down to three parts: a model, tools, and instructions.

Anthropic's post on building effective agents describes agents as "systems where LLMs dynamically direct their own processes and tool usage, maintaining control over how they accomplish tasks." The key idea in both: the AI decides what to do next, within limits you set.

How is an agent different from a ChatGPT chat?

OpenAI's getting-started guide for ChatGPT Work draws the line in practical terms. Use Chat when you want a thoughtful answer, to explore an idea, or to work through a question. Use Work when a task needs information from other apps, several steps, or a finished result you can review. Its example: confirming a team dinner when the restaurant's email is in Gmail and the headcount and dietary needs are in Slack. Work can pull those together and draft the reply.

One honest wrinkle: the line blurs. OpenAI notes that both Chat and Work can use plugins. What makes something an agent is who's running the sequence of steps.

What's the difference between an agent and a workflow?

Anthropic makes a distinction that's handy for anyone planning automation. A workflow is a system where the AI and tools follow steps that someone laid out in advance. An agent decides its own steps as it goes. Anthropic calls both "agentic systems."

Each has its place. Anthropic says workflows offer predictability and consistency for well-defined tasks, while agents fit better when you need flexibility and model-driven decisions. OpenAI's guide makes a similar point from the other direction. Agents suit work where rule-based approaches fall short, such as tasks that need judgment, rules that are hard to maintain, or lots of messy text. If your task doesn't look like that, the guide says, a deterministic solution may be enough.

In plain terms: if you can write the steps down and they never change, you probably want a workflow. If the steps depend on what the AI finds along the way, that's agent territory.

What does an agent look like inside ChatGPT today?

This has changed recently, so it's worth being precise. OpenAI's help page for ChatGPT agent now says that ChatGPT agent is no longer available, and points people to ChatGPT Work for longer, multi-step tasks and finished deliverables.

Work can use a cloud browser, a browser running on a separate computer in the cloud. OpenAI's help page says it can read web pages, click buttons, fill in forms, and carry out steps on supported websites, including ones you sign in to. A few details from that page that show the agent pattern at work:

  • You describe the outcome you want, and ChatGPT decides when to use the browser or a connected app.
  • It pauses when it needs your input, a sign-in, or a confirmation.
  • A task can keep running after you close your computer.
  • OpenAI's example tasks include requesting quotes from businesses, tracking a package using a connected email account, and reconciling invoices in accounting software.

OpenAI says cloud browser is available in ChatGPT Work on paid plans in supported regions, excluding Free and Go.

What can go wrong with an agent?

More than with a chat, because an agent acts instead of just answering. Anthropic says the autonomy of agents means higher costs and "the potential for compounding errors." A wrong turn in step two gets carried into step five.

There's also a risk called prompt injection. OpenAI's agent help page gives an example: while researching a restaurant using your calendar and email, an agent might run into a hidden instruction on a web page telling it to fetch a password reset code and send it somewhere. OpenAI describes several safeguards, including confirmations for high-impact actions, and says those measures don't eliminate all risks.

OpenAI's practical advice from the same page is worth keeping:

  1. Enable only the apps the current task needs.
  2. Avoid vague prompts like "Check my email and handle everything."
  3. Stop a task right away if something seems off.
  4. Review your app permissions regularly.

Some websites also block automated browsers, OpenAI notes, so an agent may not be able to finish every task.

When should you use a chat instead of an agent?

More often than you'd think. OpenAI's Work guide says longer or more complex tasks can take more time and use more credits, and suggests starting in Chat if a conversation is enough. Anthropic's advice to builders is the same idea: find the simplest solution that works, which sometimes means no agent at all.

A chat is the right tool for drafting, brainstorming, editing, and thinking out loud. Reach for an agent when the job spans several apps, repeats often, and ends in something you can check. If you're deciding where your team should start, read How should a 10-person company start using AI agents?

FAQ

Is a custom GPT an agent?

It depends on what it does. By OpenAI's definition, an app that uses an AI model but doesn't use it to run the steps of a workflow, like a simple chatbot, isn't an agent. A GPT that only answers questions from your documents is closer to a chat.

Is "agentic" the same thing as an agent?

Not quite. Anthropic uses "agentic systems" as an umbrella for both workflows, which follow predefined steps, and agents, which decide their own steps.

Will an agent buy things or send messages without asking me?

OpenAI says ChatGPT is designed to ask for confirmation before actions that are hard to reverse or create a financial, legal, or account commitment, like confirming a booking or making a payment.

Can an agent keep working after I close my laptop?

In ChatGPT Work with cloud browser, yes. OpenAI's help page says tasks run on a remote computer and continue in the background, pausing when they need information, a sign-in, or confirmation.

Do I need a paid ChatGPT plan to use agent features?

For cloud browser, yes. OpenAI says it's available in ChatGPT Work on paid plans in supported regions, excluding Free and Go.
